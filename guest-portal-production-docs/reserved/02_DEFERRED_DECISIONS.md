| Decision | Status |

| Pricing and discounts | DEFERRED |
| Billing per organization, property, room or cabin | DEFERRED |
| Trial rules | DEFERRED |
| Subscription statuses and transitions | DEFERRED |
| Renewal and expiry behavior | DEFERRED |
| Grace periods and suspension behavior | DEFERRED |
| Staff-seat limits | DEFERRED |
| Property and location limits | DEFERRED |
| Voice-minute quotas and overage | DEFERRED |
| AI usage quotas | DEFERRED |
| Knowledge-storage limits | DEFERRED |
| Payment method and payment provider | DEFERRED |
| VietQR or bank-transfer reconciliation | DEFERRED |
| Invoice and tax integration | DEFERRED |
| Self-service checkout and billing portal | DEFERRED |
| Custom enterprise contracts | DEFERRED |

A deferred decision may only be resolved by a later approved product and architecture document. Existing code, tests and fixtures must not imply a final answer.
