## 4. Form patterns

- Single-column form for simple setup.
- Two-column label/control only when readability remains.
- Side inspector for builder.
- Drawer for quick edits under 8 fields.
- Full page for complex objects.
- Dialog only for confirmation or short task.

Every form:

- Server/client validation consistency.
- Required marker.
- Field error.
- Form-level error.
- Dirty state.
- Save state.
- Cancel behavior.
- Keyboard submit behavior.
- Unsaved changes guard where needed.
