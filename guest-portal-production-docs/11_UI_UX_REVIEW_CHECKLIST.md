# UI/UX Review Checklist

## Global

- [ ] Spacing nhất quán.
- [ ] Typography đúng hierarchy.
- [ ] Không text bị cắt.
- [ ] Không horizontal scroll ngoài ý muốn.
- [ ] Loading, empty, error đầy đủ.
- [ ] Action chính rõ.
- [ ] Destructive action xác nhận.
- [ ] Focus rõ.
- [ ] Keyboard usable.
- [ ] Contrast đạt.
- [ ] VI/EN không vỡ layout.
- [ ] Mobile/touch target đạt.

## Admin

- [ ] Primary sidebar.
- [ ] Secondary sidebar khi cần.
- [ ] Workspace có breadcrumb/title/action.
- [ ] Filter/search dễ tìm.
- [ ] Table không quá dày.
- [ ] Builder có canvas/inspector rõ.
- [ ] Publish status rõ.
- [ ] Autosave status rõ.

## Staff

- [ ] Inbox ưu tiên việc mới.
- [ ] Claim/status action ít bước.
- [ ] Chat không tách rời item.
- [ ] Mobile bottom nav.
- [ ] Realtime/reconnect state rõ.
- [ ] Không yêu cầu zoom.

## Guest

- [ ] Cover/logo hợp lý.
- [ ] Quick action trên fold.
- [ ] Voice/text dễ thấy.
- [ ] Locale dễ đổi.
- [ ] Request/order status dễ hiểu.
- [ ] Không bắt đăng nhập.
- [ ] Mạng chậm vẫn usable.
