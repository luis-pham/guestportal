# Phase 09 — Admin Operations and Analytics

## Scope

- Request/order management.
- Staff management.
- Knowledge operations.
- QR analytics.
- Basic dashboard.
- Filters/export.
- Audit log viewer.
- Settings.
- VI/EN.

## Acceptance criteria

- Dashboard dùng dữ liệu thật.
- Filter theo property/date/status.
- Export bảo vệ quyền.
- Empty/loading/error.
- Data table usable.
- Deep link tới item.
- Analytics query không leak tenant.

## Test bắt buộc

- Aggregation integration.
- Permission.
- Large list pagination.
- Export.
- Timezone.
- Locale.
- Visual regression.
- Performance query.
