# Definition of Done

Một feature chỉ được xem là Done khi:

- Code hoàn chỉnh.
- Không có placeholder trong production path.
- Domain rule có test.
- API có validation.
- Authorization đầy đủ.
- Multi-tenant filter đầy đủ.
- UI có loading/empty/error/success.
- VI/EN hoàn chỉnh với Admin/Staff.
- Responsive theo yêu cầu.
- Accessibility smoke.
- Logging/metrics phù hợp.
- Documentation cập nhật.
- Test chạy PASS.
- Evidence được lưu.
- Không còn S0/S1.
- Reviewer có thể chạy lại từ tài liệu.
